# clima-cim

Painel meteorológico público do **Centro Integrado de Modelismo (CIM)**, em Eusébio-CE.

## Dados do campo

- Pista: **13 / 31**
- Comprimento: **230 m**
- Coordenadas de referência iniciais: **-3.8455, -38.4596**
- Fuso horário: **America/Fortaleza**

## Funcionalidades

- Condições meteorológicas atuais via Open-Meteo
- Temperatura e sensação térmica
- Umidade, pressão e visibilidade
- Vento e rajadas
- Direção do vento
- Seleção automática da pista preferencial 13 ou 31
- Cálculo de componente longitudinal de vento (proa/cauda)
- Cálculo de componente de través
- Probabilidade de chuva e índice UV
- Janela meteorológica para as próximas horas
- Previsão para 7 dias
- Atualização automática a cada 15 minutos

## Publicação com GitHub Pages

No GitHub, abra:

**Settings → Pages → Build and deployment → Source: Deploy from a branch**

Selecione:

- Branch: `main`
- Folder: `/(root)`

Depois clique em **Save**.

O endereço esperado será:

`https://detohiluy.github.io/clima-cim/`

## Observação

Os indicadores de condição para voo são auxiliares e não substituem a avaliação do piloto no local, incluindo observação da biruta, estado da pista e condições reais do espaço aéreo.
