Fontes, atualização e metodologia

Open-Meteo: estimativa de modelos meteorológicos para -3.845481 / -38.460447. A condição atual é baseada em dados de modelo em resolução de aproximadamente 15 minutos; somas como precipitação representam o intervalo precedente indicado pela API. A consulta ocorre ao abrir a página e a cada 5 minutos.

METAR/TAF: SBFZ via metars.eu, cujo upstream é NOAA/AWC. METAR com mais de 90 minutos é rejeitado pelo painel. Esses boletins são contexto regional, não sensores instalados no CIM.

Indicador CIM: FAVORÁVEL / ATENÇÃO / DESAFIADOR / DESFAVORÁVEL é uma heurística meteorológica do site. Não é limite legal, certificação de segurança, nem limite de fabricante de um aeromodelo.

Fontes: Open-Meteo · NOAA/AWC · metars.eu API · Windy Embed.

CIM · Centro Integrado de Modelismo. Painel auxiliar de consciência meteorológica. Confirme sempre a biruta, o céu, a pista, o tráfego e a situação regulamentar antes de voar.
